# Java Calculator

A simple GUI-based calculator developed using Java Swing.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Graphical user interface (GUI)

## Technology Used

* Java
* Java Swing
* AWT

## How to Run

1. Install Java JDK.
2. Open `Calculator.java` in VS Code or any Java IDE.
3. Compile and run the program.
4. Use the calculator buttons to perform calculations.

## Project Purpose

This project was created to practice Java programming, GUI development, event handling, and basic arithmetic operations.
